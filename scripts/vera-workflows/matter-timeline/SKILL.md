# Matter Event Timeline

Work only from the current Matter's pinned source DocumentVersions. Create one real, source-linked event Timeline in the existing Tabular Review object; it is not an Excel document. Every event must retain one or more exact, relocatable citations to a pinned source. Preserve uncertain dates, conflicts, and unknown facts rather than inferring them.

Process: read pinned sources; identify supported events and date precision; add the events to the fixed Timeline; verify the Timeline, all source pins, and every citation. Pause on missing sources, source-version drift, an unsupported source type, a material citation gap, an unresolved conflict, missing facts, scope expansion, or consequential action. The Timeline is an editable work product, not lawyer approval or external delivery.
